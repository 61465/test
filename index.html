1. نظرة عامة والهدف من المشروع

يركز هذا المشروع على محاكاة وتوضيح الانتقال الجوهري في تطوير البرمجيات من "البرمجة الحدسية" (Vibe Coding) - وهي كتابة الأكواد بالاعتماد الكلي على التوجيه دون ضوابط - إلى "هندسة الوكلاء الذكية" (Agentic Engineering) - حيث تعمل النماذج بشكل مستقل ومضمون داخل حاويات احتواء مغلقة وتحت حماية بروتوكولات الأمان والاختبار.

2. المكونات المعمارية والتقنية للأيام الـ 5

  • القفص الاحتوائي (Harness ~90%): محاكاة ثلاثية الأبعاد لعزل النموذج وتحديد درجة الحرارة ومحددات الحماية لضمان توافق التنفيذ مع الأمان.
  • حلقة الوكيل المصححة ذاتياً (Self-Correcting Loop): طرفية محاكاة لخطوات الإدراك، التخطيط، العمل، المراقبة، والتكرار لحل المشاكل آلياً.
  • مختبر الكود الأمني (Stripe Audit): اختبار ثغرات بوابات الدفع (Stripe Webhooks) وحلها تلقائياً بتوليد توقيع تشفيري آمن.
  • بروتوكول MCP (Model Context Protocol): استكشاف الأدوات واستدعاء خدمات الوثائق وقواعد البيانات الخارجية باستخدام payloads من نوع JSON-RPC 2.0.
  • مستودع المهارات الديناميكي (Dynamic Skills): عزل قدرات المساعد في مجلدات مستقلة تدار بملف مركزي SKILL.md لحماية الذاكرة من عفن السياق.
  • نظام الأمان والتحكم البشري (HITL): اعتراض العمليات الحساسة التي تتطلب تفويضاً مالياً وتوفير ثقة فعالة مستمرة (Effective Trust).
  • التطوير الموجه بالمواصفات (SDD Gherkin): كتابة مواصفات السلوك الحتمية كلغة مرجعية لا تتبدل، واعتبار الكود المولد قالباً مستهلكاً وقابلاً للإبدال.

🎓 Certified Capstone Submission

Antigravity: Interactive Agentic Workspace Showcase

5-Day AI Agents Intensive Course by Google & Kaggle | June 2026

Presented by: Abd Alrahaman gz

1. Abstract & Use Case

This project models the critical evolution in software engineering from **"Vibe Coding"** (casual, unvalidated prompting) to **"Agentic Engineering"**. It demonstrates how autonomous agents run self-correcting loops (Perceive-Plan-Act-Observe-Iterate) inside secure container boundaries (the **Harness ~90%**), verify security configurations, implement standard tool protocols (MCP), and execute pay-as-you-go billing (AP2) under secure human supervision.

2. Core Technical Implementations (5-Day Syllabus)

  • Containment Harness (~90%): 3D bounding box visualization illustrating how model temperature, guardrail policies, and sandbox systems constrain model execution.
  • Self-Correcting Trace Loop: CLI trace console compiling tasks, trapping terminal execution errors, and running auto-repair attempts.
  • Security Sandbox Auditor: Practical auditing of Stripe webhook signature verification to secure payment flows automatically.
  • Model Context Protocol (MCP) Hub: Interoperability demo showing client-server JSON-RPC 2.0 requests for tool list discovery and DB tool execution.
  • Dynamic Skills Registry: Encapsulates prompt capabilities into standalone directories powered by portable SKILL.md configurations to avoid context rot.
  • Effective Trust & HITL: Bounding container parameters, auditing sandbox threats, and executing Human-in-the-loop intercept dialog gateways for sensitive transactions.
  • Spec-Driven Development (SDD): Enforcing Gherkin BDD specifications (.feature) to govern exact agent capabilities, treating raw generated code as fully disposable.
